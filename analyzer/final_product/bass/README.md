# Bass Final-Product Engine

Bass is a separate professional engine modeled structurally on Rhythm but built around true Bass separation and four-string playability.

The intended Bass pipeline is:

```text
deterministic Bass separation
→ Bass Hz/pitch evidence
→ Bass candidate selection
→ authenticated timing/grid placement
→ four-string G-D-A-E string/fret mapping
→ Bass-specific techniques
→ structured Bass events
→ Bass quality gate
→ professional four-string Bass TAB rendering
```

Bass owns its own:

- Hz/frequency ranges and features;
- Bass training datasets/models/checkpoints;
- four-string tuning/fretboard rules;
- Bass technique evidence;
- Bass quality thresholds;
- Bass professional engine identity;
- four-string PDF/TAB rendering.

Existing inactive scaffolds already prove deterministic direct/cascade Bass separation, a four-string render contract, and a fail-closed synthetic Bass quality gate. Those scaffolds are prerequisites only; they do not activate customer routing or professional Bass identity.

Real-audio Bass separation/analysis quality must be proven before this engine can replace the legacy Bass customer path.
