# Rhythm Professional PDF Engine

Rhythm owns six-string professional Rhythm TAB engraving based on authenticated Rhythm events.

The proven V143 renderer remains the reference implementation. Migration into this final-product folder must preserve its behavior and evidence before any active import path changes.

Expected inputs include authenticated measure/step placement, MIDI pitch, six-string string/fret position, duration/sustain, Rhythm techniques, tuning, tempo, meter, and metadata.

Preview and full/unlocked Rhythm PDFs must use the same authenticated analysis and differ only in reveal/preview policy, not musical content.
