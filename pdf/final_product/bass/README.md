# Bass Professional PDF Engine

Bass owns true four-string professional Bass TAB engraving.

The renderer must use Bass-specific string labels and tuning (`G-D-A-E` for Standard Bass), four-string playability, Bass fret limits, Bass techniques, and Bass metadata. It must not reuse a six-string guitar staff merely because event fields are numerically compatible.

Expected inputs include authenticated measure/step placement, MIDI pitch, four-string string/fret position, duration/sustain, proven Bass techniques, tuning, tempo, meter, key and metadata.

The existing Bass render-contract scaffold is a prerequisite only. This renderer remains inactive until a reference-free real-audio Bass analyzer passes its quality gate and earns a distinct professional identity.
