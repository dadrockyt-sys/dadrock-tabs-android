## Source-verified diagnostic facts (not speculative causal claims)

1. **Consistency normalization:** `astra_backend/guitartechs_training_v9/paired_view.py` blob `9b704ea9c5bf153197dfde260c1b995142d062b5` uses symmetric `F.kl_div(..., reduction="batchmean")` on `[B,T,6,21]`, summing class/string/frame dimensions and dividing by `B`. `train_v9_resumable.py` blob `99cae61a0a299de27a24e367afccdf7b13a7c81b`, lines 400–415, sets `loss = 0.5*(supervised_a + supervised_b) + 0.10*consistency`. At fixed `T=200`, `batchmean = 200×6×per_position_mean_KL = 1200×` (for fully present positions). Thus the consistency contribution is `120×per_position_mean_KL`, **not** `0.10×per_position_mean_KL`. Pure numeric fixture (two-class P=(.75,.25), Q=(.25,.75), same distributions at 1,200 positions): symmetric per-position KL=0.5493061443340548; batchmean=659.1673732008658; weighted term=65.91673732008657; desired per-position-weighted illustrative term=0.05493061443340548. These are arithmetic properties, **not observed V9 gradients**. In particular, the run's relative KL/supervised gradient influence is unknown.
2. **Augmentation units:** `astra_backend/tabcnn_runtime/preprocessing.py` blob `e1d251a341b811b1b8e2df97d78b754d3379046b` builds relative dB CQT features `amplitude_to_db /80 + 1`; V9 paired-view multipliers, noise, bin tilt and masks operate on already-extracted features or overlapping windows. They are not demonstrably physical audio gain, SNR or dB-per-octave, and not demonstrated acoustically label-preserving. The tensor time mask is applied after context-window construction; correlated source-frame windows need not receive the same perturbation.
3. **Decoder admission cannot be rescued by event scaling:** `astra_backend/guitartechs_training_v8/decoder.py` blob `0d856504983afdeeba2c18ad11b3090164876243` first calls V4 `decode_with_hysteresis`, and V7 event ranks can only backshift the start of an already-admitted active run by ≤2 frames. `astra_backend/guitartechs_training_v4/objective_decoder.py` blob `b9a96f6b256de52bfbb5076482a03263415213cb` requires strong start ≥0.55 and above silence, or fixed two-frame confirmation (0.42 initial, 0.35 next, silence ratios 0.90/0.80); continuation ≥0.35 and ≥0.80×silence; gap merge ≤2 and prune active runs <2 frames. If V4 admits no runs, V8 event-rank calibration cannot create any.
4. **Metrics underdetermine emitted counts:** `astra_backend/guitartechs_real_training/real_training.py` blob `d4a3dd99c4a2c3cda16c10bde1a5dc63f6380254`, `capture_metrics` lines 239–264, computes F1 and completeness from matched run counts/overlap but does not return predicted, reference or TP event counts. `abstentionRate` is **hard-coded 0.0**. `frameAccuracy` averages only positions where reference *or prediction* is active (excluding jointly inactive positions). So the frozen result's “no admitted events” prose remains **unverified**. No V9 result should be rewritten.
5. **Checkpoint selection:** trainer lines 62–69 rank `(f1, completeness, -abstentionRate, -epoch)`; epochs 20–1000 tied on the logged first three components, making epoch 20 the deterministic earliest-epoch selection. The selected full-validation result used that epoch-20 checkpoint; full-validation scores were **not** independently computed for each of the other 49 checkpoints. Do not call epoch 20 evidence of early convergence, change the selected checkpoint, or claim all full-validation checkpoints were tested.
6. **Verification gap:** synthetic checks `astra_backend/guitartechs_training_v9/verify_synthetic_v9.py` blob `a7f164751e24fd5a498b30ea3085596f897bbf23` check shape, finite gradient and determinism for a short tensor, not component-wise scaled V9 composite gradients.
