## Major new lead — Arty dataset (Sebastian Franjou, MIT, 2022)

Primary thesis metadata for `Arty: Expressive timbre transfer using articulation detection for guitar` describes a new electric-guitar dataset created specifically as ground truth for MIR development.

### Signal path / population

- Direct-to-interface electric-guitar recordings.
- Ibanez JSM-10 electric guitar, neck pickup.
- M-Audio 2x2M or Behringer UM-2 interface.
- Recorded into Logic Pro X at 44.1 kHz and exported as WAV.
- The dataset was played by the author and covers every fret below the 12th fret on every string for the supported excitation/expression combinations, with normal, slide and vibrato expression styles and pick/fingerstyle/palm-mute excitation styles.

### Exact note-event semantics

The thesis explicitly states that every note is annotated with:

- MIDI pitch;
- onset time in seconds;
- offset time in seconds;
- plucking/excitation style;
- expression style.

The XML example contains fields including `onsetSec`, `pitch`, and `offsetSec`. The appendix defines `pitch` as MIDI pitch, `onsetSec` as absolute note onset in seconds, and `offsetSec` as absolute note offset in seconds.

### Reference-independence evidence

This is the important distinction from GIHME/MMIP/DoMP.

The thesis describes a Sonic Visualizer annotation layer in which each text file corresponds to an audio file and each line stores onset time, region number, and offset time. It then states that these timings were **hand annotated from the audio files in Sonic Visualizer**. The MusicXML supplies pitch/playing-technique information; the Sonic Visualizer timing and MusicXML are combined into the final note-event representation, and each audio file has a JSON serialization of the note events “as annotated by the author.”

Therefore the reference event timing is not documented as being generated by Basic Pitch, NeuralNote, Aubio/YIN, Fishman TriplePlay, or another AMT/pitch-estimation system. The Arty application itself later uses automatic pitch processing, but that is distinct from the documented ground-truth annotation pipeline.

## Robot-played guitar direction — useful acquisition method, current corpus not sufficient

Public GitHub metadata for `gerelmaab/Physically_augmented_guitar_chord_dataset` states that the dataset was recorded directly from a guitar-playing robot, covers 97 chord classes and five stroking patterns, and was manually chord-annotated. The associated publication describes the public data as audio recordings with chord labels.

This acquisition paradigm is useful because known robot commands could in principle provide independent pre-audio event truth. However, the released/public metadata for this corpus does not expose per-note command timestamps or exact note-onset + integer-MIDI event logs.
