## Major source/access update — RWC Instruments is now openly and stably released

The RWC Musical Instrument Sound Database (`RWC-MDB-I-2001`) was officially re-released on Zenodo in February 2026 as `RWC Instruments Database`, version `v1`, DOI `10.5281/zenodo.17170844`.

Public record facts:

- dataset is open;
- license: CC BY-NC 4.0 for research/noncommercial use;
- stable Zenodo DOI/version identity;
- archive `RWC-I.zip`, approximately 14.2 GB;
- published MD5 `fb5789335fe68abdc09929618e9f0403`;
- original database is described as copyright-cleared research data;
- files hold individual sounds with mute gaps, generally ordered in ascending pitch at semitone intervals;
- for string instruments, the total range is recorded per string.

This removes the historical RWC-I access/license ambiguity that existed when MINST required direct AIST access.

## MINST onset provenance

Public repository `ejhumphrey/minst-dataset` remains useful as an independently inspectable annotation/tooling source.

Relevant code-level findings:

- `minst/sources/rwc.py` parses RWC filenames only into instrument, playing-style and dynamic metadata and attaches a stored onset-file path; it does not estimate or infer pitch from audio.
- `scripts/collect_onsets.py` explicitly collects `*-fix.csv` files generated by the interactive annotation workflow and notes that this path was set up for the RWC annotations.
- the project README states that estimated onsets are to be verified and corrected as needed with the annotation GUI.
- `scripts/split_audio_to_clips.py` reads the saved onset CSV and cuts the actual source recording at those onset times; it performs no pitch estimation.

Therefore MINST's stored onset marks can plausibly provide human-verified actual-performance onset timing independent of AMT/pitch estimation. However the MINST segmentation path itself does not attach note pitch labels to RWC observations, so pitch authority must come independently from the RWC performance protocol / source metadata.

## Independent RWC classical-guitar pitch/event semantics — Szczupak 2008

A 2008 COPPE/UFRJ M.Sc. dissertation by Alexandre Leizor Szczupak, `Identificação de Notas Musicais em Registros Solo de Violão e Piano` (`Musical Notes Identification in Solo Recordings of Acoustic Guitar and Piano`), supplies unusually precise metadata for the RWC classical-guitar subset.

The dissertation identifies nine RWC files:

- `091CGAFP`, `091CGAFM`, `091CGAFF`;
- `092CGAFP`, `092CGAFM`, `092CGAFF`;
- `093CGAFP`, `093CGAFM`, `093CGAFF`.

It states that these are three different classical guitars, apoyando technique without pick, at piano/mezzo/forte dynamics. Each recording contains exactly 78 individual note sounds: the 13 lowest notes on each of the six strings. It further explains that a given pitch may occur on multiple strings and gives concrete fret/string examples.

The same dissertation states the guitar's lowest note as E2 (~82.41 Hz) and describes the normal guitar range through B5. Combined with standard tuning/string identity and the explicit 13-position per-string acquisition protocol, the performed pitch identity is deterministic from the physical string/fret sequence rather than inferred from the audio.

### Onset authority

The dissertation's segmentation section states that:

- some RWC onset proposals came from marks supplied by Chunghsin Yeh;
- some came from an onset-detection algorithm;
- some were manually marked;
- **all marks were reviewed and corrected when necessary**;
- segment offsets were defined from the next onset (or file end for the final event);
- the RWC onset marks used in the work are listed in Appendix A.1.

This matters because the final reference onset is human-reviewed/corrected against the real recording rather than blindly inherited from an automatic detector. The source does not use AMT/pitch estimation to generate pitch truth.

During metadata research, indexed PDF text exposed several numeric onset sample values for `091CGAFP` from Appendix A.1. Accordingly, that exact appendix/file must be treated as **pre-PRE annotation-exposed in this research session** and must not be silently claimed as untouched prospective evaluation evidence.
