## Original RWC file-order semantics materially strengthen pitch mapping

The original AIST `RWC Music Database: Musical Instrument Sound` documentation states:

- for each instrument playing style, individual sounds were generally recorded at half-tone intervals over the playable range;
- for string instruments, the total range was recorded for each string;
- each WAV file is, in principle, a collection of individual sounds **in ascending pitch order** with a mute gap between adjacent sounds;
- file names encode instrument number, variation, instrument symbol, playing-style symbol, and dynamics;
- Instrument No. 09 is Classic Guitar (Nylon String), with three variations and four playing styles per variation.

This is primary-source acquisition metadata and does not depend on AMT/pitch estimation.

## Independent classical-guitar subset protocol remains precise

Szczupak's 2008 dissertation identifies the exact files:

- `091CGAFP`, `091CGAFM`, `091CGAFF`;
- `092CGAFP`, `092CGAFM`, `092CGAFF`;
- `093CGAFP`, `093CGAFM`, `093CGAFF`.

It states that:

- these are three different classical guitars;
- playing style is apoyando without pick;
- P/M/F are piano/mezzo/forte dynamics;
- each file contains exactly 78 individual note sounds;
- those 78 sounds are the 13 lowest note positions of each of the six strings;
- the same pitch can intentionally occur on multiple strings;
- example: A2 occurs both as sixth-string fret 5 and open fifth string.

Independent RWC instrument-identification literature gives the classical-guitar family pitch range as `E2–E5` and identifies `091CGAFM` as variation-1 / mezzo / apoyando-finger material.

## Deterministic ordinal-to-pitch mapping — substantially established, final tuning provenance still to close

Because the primary RWC source says file events are stored in ascending pitch order, duplicate physical string/fret positions do not create a MIDI-label ambiguity: equal-pitch duplicates have the same integer MIDI value regardless of their ordering among themselves.

The documented six-string × 13-position protocol therefore defines a 78-note pitch multiset. Under normal six-string classical-guitar tuning, the open-string MIDI values are:

`[40, 45, 50, 55, 59, 64]` = E2, A2, D3, G3, B3, E4.

Adding frets `0..12` to each open string and sorting the resulting 78 MIDI values gives a deterministic ordinal MIDI sequence spanning E2 (40) through E5 (76), exactly matching the independently published RWC classical-guitar range.

The source lineage directly confirms E2 as the lowest guitar note and the A2 sixth-string-fret-5 / fifth-string-open equivalence. However, this pass did not surface a single primary RWC table explicitly printing all six open-string pitches for these exact recordings.

Therefore the conservative status is:

`ORDINAL_TO_MIDI_MAPPING_STRONGLY_DETERMINED_BY_PRIMARY_ASCENDING_ORDER + DOCUMENTED_6x13_PROTOCOL / NORMAL_TUNING CONSISTENT_WITH PUBLISHED RANGE_AND_EXAMPLES / ONE_MORE_SOURCE-LINEAGE TUNING CONFIRMATION DESIRABLE BEFORE PRE`

Do not weaken this remaining documentation check merely because standard tuning is conventional.
